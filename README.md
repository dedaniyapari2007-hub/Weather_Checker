# Weather Dashboard

A command-line Python application that fetches live weather data, stores historical readings in a SQLite database, and visualizes temperature trends over time.

## Features
- Fetches real-time weather data from the OpenWeatherMap API
- Stores every weather check in a local SQLite database
- View historical weather readings for any searched city
- Plot temperature trends over time using matplotlib
- Simple interactive command-line menu

## Tech Stack
- Python 3
- `requests` (API calls)
- `sqlite3` (data storage)
- `matplotlib` (data visualization)
